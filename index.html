📖 使用说明

这是一个全能工作台，共 7 个栏目。点顶部导航切换，下面逐个展开看怎么用。所有数据都存在你自己的浏览器里，不会上传。
🏠 主界面（桌面）
仿 Win11 桌面，有动态壁纸和桌面小组件（时钟、天气、待办、音乐等）。
• 小组件可拖动，在「设置」里开关。
• 壁纸、主题色在「设置」里换。
• 卡顿的话把「设置→性能模式」调到中或低。
📚 导航
常用网站导航，按 AI / 开发 / 学习 / 影音 等分类。点卡片在新标签页打开网站，顶部搜索框可直接搜。
🖥️ 分屏浮窗
像电脑一样多窗口并排工作。
• 点左下角「☰ 应用」打开窗口。
• 窗口可拖动、缩放（支持触屏）。
• 用顶部「双分屏 / 三分屏 / 层叠」一键排版。
💬 聊天（广域网可用）
基于公共服务器的实时聊天，全世界联网设备都能互通。
  1. 填用户名。
  2. 填一个房间名（告诉对方相同房间名）。
  3. 点「进入聊天室」，同房间的人即可实时聊天。
🎮 游戏（能赚积分）
内置十几款小游戏（2048 / 贪吃蛇 / 坦克大战 / 扫雷 等），玩游戏会攻积分。
• 积分能在「主题卡池」抽奖，也能在设置里兑换整套主题。
• 手机上可触屏 / 滑动操作。
• 坦克、聊天式游戏支持房间号联机对战。
🤖 AI 助手（重点）
DeepSeek 风格的 AI 聊天，需要你自己的 API 密钥才能用：
  1. 点顶部「🤖 AI」栏目。
  2. 点左下角「⚙️ API 设置」，填入 API Key（地址默认已填好 DeepSeek，也可改成 OpenAI / 通义 / Kimi 等兼容接口）。
  3. 保存后就能对话。Enter 发送，Shift+Enter 换行。
• 🎤 语音：点麦克风说话，自动转文字（建议 Chrome / Edge）。
• 📎 文件：可传文本 / 代码 / 图片一起问。
• 🎨 界面自定义：改 AI 名称 / 头像 / 气泡颜色 / 字号 / 聊天背景。
• 左侧可建多个会话，自动保存。
密钥只存在本机浏览器，不会上传。
⚙️ 设置（当前页）
• 主题：用积分兑换整套主题（壁纸+配色+文案）。
• 主题色：自定义全站强调色。
• 背景音乐：上传音乐或贴网址，切页不断播。
• 界面与启动：自动隐藏导航 / 任务栏、性能档位、启动页面等。

🎭 主题（积分兑换）

玩游戏攒积分，兑换整套主题：壁纸 + 配色 + 界面文案一起换。异环 / 鸣潮 / 三角洲的壁纸放在 themes 文件夹里（和本 HTML 一起上传 GitHub），没放也有内置壁纸兜底。你自己改主题色或壁纸时会自动切到「自定义」。

🎨 主题色

改变全站按钮、选中标签等强调色

📦 数据管理

所有设置、待办都保存在本浏览器（localStorage），不会上传

ℹ️ 关于聊天的广域网说明

聊天功能默认使用公共 MQTT 服务器（broker.emqx.io）中转消息，天生就是广域网的： 只要双方能上网，无论在不在同一个网络、相隔多远，输入相同房间名即可互聊。 注意：公共服务器上的消息不加密，别发隐私/密码；想更私密可自建 MQTT 服务器后在聊天页换掉服务器地址。
